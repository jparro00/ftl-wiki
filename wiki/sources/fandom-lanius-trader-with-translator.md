# Fandom — "Lanius trader with translator"

## Summary
Community wiki page for `LANIUS_TRADER_TRANSLATOR`, retrieved via the MediaWiki API at
revision 74244. Documents the shared trade table and the 40-scrap Lanius crew purchase, and
spells out the asymmetry with the near-identical [[event-lanius-trader]].

## Key Takeaways
- **Names the in-game id**: *"This event is called 'LANIUS_TRADER_TRANSLATOR' in the
  datafiles."*
- Location: Abandoned Sector; `LRSmap=noship`, `unique=true`.
- Trade table matches the XML: 3–7 fuel → 15–30 scrap, 3–7 missiles → 20–40, 3–7 drone parts
  → 20–40 — the same `LANIUS_TRADER_LIST` the sibling event uses.
- Confirms the crew purchase: 40 scrap for *"a Lanius crewmember named Translator"*.
- States the asymmetry directly: this event sells the crew member but **has no blue option**,
  whereas [[event-lanius-trader]] has the blue reroll but no crew.
- Categorised *Trading Events*, *Crew purchase opportunity*, *Advanced Edition Content
  Events*.
