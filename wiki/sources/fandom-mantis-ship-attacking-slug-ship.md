# Fandom — "Mantis ship attacking Slug ship"

## Summary
Community wiki page for `SLUG_DISTRESS_MANTIS`, retrieved at revision 74264. Three choices
and the post-victory "finish them off" branch.

## Key Takeaways
- Names the in-game id in Notes: *"This event is called 'SLUG_DISTRESS_MANTIS' in the
  datafiles."*
- Names both enemy ship ids (`SLUG_DISTRESS_MANTIS`, `SLUG_DISTRESS_MANTIS_SLUG`) in
  reference notes and records that **neither surrenders nor escapes** — matching
  [[source-events-ships]].
- Reward tiers match the files: `MED standard` for beating the Mantis, `HIGH standard` for
  killing the Slugs directly, `LOW augment` on the augment branch.
- Renders `<autoReward level="RANDOM">standard</autoReward>` as *"a random amount of scrap
  with resources"* — the only gloss available for that level anywhere in this batch.
- Confirms "Finish them off" does **not** start a second fight.
- Category: `Augmentation reward chance`.
