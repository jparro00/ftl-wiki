# Fandom — Engi smashed ships

## Summary
FTL Fandom wiki page for `ENGI_SEX` (revision 74050, retrieved 2026-08-09). A DLC neutral
event: two Engi ships locked together, with an Engi-crew blue option that reveals the
joke and pays out.

## Key Takeaways
- Confirms the "pry them apart" fight against `ENGI_SEX_SHIP` yields **nothing** on
  victory — the ship's `destroyed`/`deadCrew` blocks carry no `autoReward`.
- Carries an editorial note that the blue-option reward line is written
  `<autoReward level="MEDIUM">` where the game expects `MED`, and that the engine
  therefore treats it as `RANDOM`. This is a Fandom claim about engine behaviour, not
  something the game files state.
