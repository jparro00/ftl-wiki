# Fandom — "No fuel: Slug fuel trader"

## Summary
Community wiki page for `FUEL_ON_SLUG_CHUCKLE`, retrieved at revision 63806. Documents the
15-scrap-for-5-fuel trade and its theft branch.

## Key Takeaways
- **Names the in-game id:** *"This event is called 'FUEL_ON_SLUG_CHUCKLE' in the
  datafiles."*
- Marks it `{{Locations|outoffuel=distresson}}`, matching the XML.
- Lays out both `FUEL_ON_SLUG_CHUCKLE_LIST` entries as separate outcomes with identical
  opening text, one of which continues into the theft — consistent with the 1/2 split
  derivable from the two-entry list.
- Reads the theft as **2–4 missiles and 20–35 scrap**, matching the `item_modify steal`
  ranges in the XML.
- Categorises the event as scrap-loss and missiles-loss risk; **no combat category**, which
  agrees with the XML — the Slug ship never turns hostile here.
