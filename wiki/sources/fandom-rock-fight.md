# Fandom — "Rock fight"

## Summary
Community wiki page for `ROCK_SHIP`, retrieved via the MediaWiki API at revision 73846.
Transcribes all eight intro variants and states the single outcome: fight a Rock ship for
default rewards.

## Key Takeaways
- **Names the in-game id**: *"This event is called 'ROCK_SHIP' in the datafiles."* This is
  what disambiguates the *event* `ROCK_SHIP` from the *enemy ship* `ROCK_SHIP` defined in
  `events_ships.xml`, which several other pages reference.
- Locations: Rock Controlled Sector, Rock Homeworlds; `LRSmap=ship`, `unique=false`.
- Transcribes all eight `textList ROCK_SHIP` variants.
- Categorised `Fights with Default Rewards` — the page states no scrap numbers of its own.
- **Does not mention the surrender branch** (`ROCK_SHIP_SURRENDER`), which the game files
  attach to the enemy ship rather than the event.
