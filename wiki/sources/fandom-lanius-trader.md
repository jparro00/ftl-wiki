# Fandom — "Lanius trader"

## Summary
Community wiki page for `LANIUS_TRADER`, retrieved via the MediaWiki API at revision 74245.
Transcribes all three intro variants and both trade tables with exact ranges, and — unusually
for a Fandom event page — explains the *behaviour* of the blue option rather than just its
text.

## Key Takeaways
- **Names the in-game id**: *"This event is called 'LANIUS_TRADER' in the datafiles."*
- Location: Abandoned Sector; `LRSmap=noship`, `unique=true`.
- Both trade tables match the XML exactly: 3–7 fuel → 15–30 scrap, 3–7 missiles → 20–40,
  3–7 drone parts → 20–40; and via the blue option 20–35 / 25–50 / 25–50.
- States that **the actual trade offer is shown before you make the choice** — a
  presentation fact the game files do not record.
- Explains the blue option is a **reroll**, not an upgrade: *"a player can get a far better
  price for the same resource… However, a less beneficial outcome (in all regards) is also
  possible."*
- Explicitly contrasts it with [[event-lanius-trader-with-translator]]: this event has the
  reroll but no crew for sale.
