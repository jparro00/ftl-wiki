# Fandom — "Refugee distress (Slug)"

## Summary
Slug-sector distress-beacon variant of the drifting-refugee encounter. Declares the
datafile id: **"This event is called `REFUGEE_DISTRESS_SLUG` in the datafiles."**

> ⚠️ Body is the unexpanded template `{{Drifting Refugee Ship|introtext=distress|type=slug}}`,
> so this source contributes **no outcome data** — only the sector scope and the id.

- Sector scope: Slug Controlled Nebula, Slug Home Nebula; `distress=true`; `unique=false`.
- Unlike [[source-fandom-refugee-slug]] this page is **not** flagged `nebula=true`,
  matching the game files (the distress version has no `<environment>` tag).
- Categorised under `Pirate ship fights` — consistent with the Slug pool's ambush ship
  being `PIRATE_REFUGEE`, not a Slug ship.
