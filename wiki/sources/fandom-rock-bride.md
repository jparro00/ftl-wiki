# Fandom — "Rock bride"

## Summary
Community wiki page for `ROCK_QUEST_MARRIAGE_START`, retrieved via the MediaWiki API at
revision 73845. Covers **both** steps of the quest — the initial hail and the quest-marker
event at Numa V — on one page, which is why the wiki event page does the same.

## Key Takeaways
- **Names the in-game id**: *"This event is called 'ROCK_QUEST_MARRIAGE_START' in the
  datafiles."* It does **not** name the second-step id (`ROCK_QUEST_MARRIAGE`), which
  comes from the game files.
- Locations: Rock Controlled Sector, Rock Homeworlds; `LRSmap=noship`, `unique=true`.
- Documents the quest-marker step under a `Quest Marker` heading and confirms the reward
  split: hand her over → *"an augmentation with low scrap"*; refuse → *"a Rockman
  crewmember named Ariadne"* plus a Rock ship fight.
- **Confirms the boarding asymmetry**: `{{Winning|destroyed=true}}` → medium scrap with
  resources; `{{Winning|deadCrew=true}}` → **high**. Matches `MED` / `HIGH` in the files
  exactly.
- Categorised `Crew reward opportunity`, `Augmentation reward opportunity`,
  `Events with Quest Markers`.
