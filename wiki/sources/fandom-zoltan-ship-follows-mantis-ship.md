# Fandom — "Zoltan ship follows Mantis ship"

## Summary
The community wiki page for `ZOLTAN_DISTRESS_MANTIS`. Retrieved via the MediaWiki API at
revision 73917. Establishes the key strategic fact about the event: **both sides pay the
same**.

## Key Takeaways
- **Names the in-game id explicitly**: *"This event is called 'ZOLTAN_DISTRESS_MANTIS' in
  the datafiles."*
- **Supplies what the game files do not:** the post-fight rewards — `low` scrap with
  resources if the ship is destroyed, `medium` if you kill the crew, **identical on both
  the save-the-Mantis and help-the-Zoltan paths**. Neither side grants an item.
- Confirms the Mantis ship on path 2 has a **crew entirely composed of Mantis**.
- Locations template: both Zoltan sectors, `distress=true`, `asteroidfield=true`,
  `unique=true`, Long-Ranged Scanners `noship+asteroidfield` — so the hazard is visible
  in advance but the ship is not.
- Includes a screenshot of the beacon on the sector map.
- Categorised `Asteroid Field risk`.
