# Fandom — "Crystal scrap collector"

## Summary
The community wiki page for `CRYSTAL_SCRAP_EXCITED`. Retrieved via the MediaWiki API at
revision 73999. Documents the 35-scrap trade and both payment branches.

## Key Takeaways
- Names the in-game id: *"This event is called 'CRYSTAL_SCRAP_EXCITED' in the datafiles"*.
- **Names the two weapons** the "request another payment" branch can give: the **Crystal
  Lockdown Bomb** (`BOMB_LOCK`) and the **Crystal Burst Mark II** (`CRYSTAL_BURST_2`). The
  game file gives only the blueprint ids, so the display names come from here.
- Confirms the 35 scrap cost is flat and that accepting gives a Crystal crew member.
- Location: Hidden Crystal Worlds, `unique=true`, **no ship** on Long-Range Scanners.
- Categorised `Crew purchase opportunity`, `Weapon reward opportunity`.
