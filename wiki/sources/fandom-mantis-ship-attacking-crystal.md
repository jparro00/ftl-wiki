# Fandom — "Mantis ship attacking Crystal"

## Summary
The community wiki page for `CRYSTAL_MANTIS_CRYSTAL`. Retrieved via the MediaWiki API at
revision 74263. Documents the optional intervention fight and its reward split.

## Key Takeaways
- Names the in-game id: *"This event is called 'CRYSTAL_MANTIS_CRYSTAL' in the datafiles"*.
- Reward split confirmed: **destroyed → medium** standard, **dead crew → high** standard.
- `MANTIS_CRYSTAL`: no surrender, no escape.
- The "Contact the Crystal ship" follow-up is rendered as the `{{Crystal Ship Saved}}`
  template, which is **not expanded** in the retrieved dump — so the five `CRYSTAL_SAVED`
  outcomes had to be taken from [[source-events-xml]] instead. The same unexpanded template
  appears on [[source-fandom-pirate-ship-attacking-crystal]] and
  [[source-fandom-rebel-ship-attacking-crystal-ship]].
- Location: Hidden Crystal Worlds, `unique=false`, **no ship** on Long-Range Scanners.
