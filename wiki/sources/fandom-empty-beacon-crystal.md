# Fandom — "Empty beacon (Crystal)"

## Summary
The community wiki page for `NOTHING_CRYSTAL`. Retrieved via the MediaWiki API at revision
73657. Lists the flavour-text variants and confirms nothing happens.

## Key Takeaways
- Names the in-game id: *"This event is called 'NOTHING_CRYSTAL' in the datafiles"*.
- Lists **six** distinct text variants. The game's text list contains seven strings, but
  `text_NOTHING_CRYSTAL_1` and `_7` differ only by the words "jump away" vs "jump", and the
  page transcribes only one of that pair — so the page is complete in substance.
- Outcome: nothing happens. No reward, no risk.
- Location: Hidden Crystal Worlds, `unique=false`, **no ship** on Long-Range Scanners.
