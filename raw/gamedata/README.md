# raw/gamedata/

Drop **datamined game files** here — the highest-reliability source there is.

- Typical files: `events.xml`, `events_*.xml` (per-sector event files), `sector_data.xml`,
  `blueprints.xml`, `text_events.xml`, `autoBlueprints.xml`.
- Keep the original filename where possible so citations read well. If you have both
  vanilla and AE copies, suffix them: `events-ae.xml`, `events-vanilla.xml`.
- Partial pastes are fine — an excerpt of one `<event>` block is a perfectly good source.
  Name it for what it covers, e.g. `giant-alien-spiders-event-block.xml`.
- **Never edited after drop-in** — this is source-of-truth. Claude reads it, it doesn't change it.

Then tell Claude: **"Ingest raw/gamedata/<file>"**.
