# raw/wiki/

Drop **community sources** here — FTL wiki pages, guides, forum threads, reddit posts,
tier lists, anything written by other players.

- One file per page or thread. Name it for the topic: `rock-homeworlds-page.md`,
  `blue-options-guide.md`.
- Paste the text as-is. Include the URL and the date you pulled it at the top if you
  have them — it helps Claude judge whether the source predates Advanced Edition.
- **Note the game version if the source states one.** Most source disagreements in this
  wiki turn out to be AE vs vanilla.
- Reliability: medium. Game files in `raw/gamedata/` outrank these when they conflict.
- **Never edited after drop-in** — source-of-truth.

Then tell Claude: **"Ingest raw/wiki/<file>"**.
