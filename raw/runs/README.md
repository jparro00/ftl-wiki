# raw/runs/

Drop **your own playthrough notes** here — what you actually saw happen at a beacon.

- One file per run or session. Name it `YYYY-MM-DD-short-label.md`
  (e.g. `2026-08-09-kestrel-hard-run.md`).
- Freeform is fine. Useful to record: sector, beacon type, event text, the choice you
  took, what happened, and your ship/crew at the time (blue options depend on it).
- Reliability: low — **one observation is not a probability**. Claude will file what you
  saw as an observed outcome, not as the odds. Several runs disagreeing about an outcome
  is exactly the kind of contradiction this wiki is built to keep.
- **Never edited after drop-in** — source-of-truth.

Then tell Claude: **"Ingest raw/runs/<file>"**.
